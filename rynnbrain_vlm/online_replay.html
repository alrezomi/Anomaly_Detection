What do the timings and cache checks mean?

Cached feature processing / Feature time: time to extract the feature using stored model history. Observation → result: delay from the observed frame to its result, including the extra full recomputation when checking the cache. This is not the failure detection timing error.

Cache check: compares cached and fully recomputed features, scores and threshold decisions. A failed check is not a robot failure. Diagnostics continue with the uncached score when a check fails; cached-only replay makes no comparison. Scores are for all selected observations so far.

Score difference: absolute cached/uncached difference, in percentage points for logistic regression or distance units for kNN. Hover over a check for its details. Settings apply when you start the next execution; the model stays loaded.
